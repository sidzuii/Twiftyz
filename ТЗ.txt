# Техническое задание

# Проект

Разработка современного кроссплатформенного мессенджера с поддержкой личных сообщений, групп, каналов, звонков, обмена файлами, шифрования и синхронизации между устройствами.

---

# 1. Цель проекта

Создать быстрый, безопасный и масштабируемый мессенджер для общения пользователей с поддержкой мобильных устройств, веб-версии и настольных приложений.

---

# 2. Платформы

* Web
* Android
* iOS
* Windows
* macOS
* Linux

Все приложения используют единый Backend и синхронизируются в реальном времени.

---

# 3. Регистрация и авторизация

Поддержка:

* регистрация по номеру телефона;
* регистрация по электронной почте;
* вход по одноразовому коду;
* двухфакторная аутентификация;
* восстановление доступа;
* подтверждение новых устройств;
* управление активными сессиями;
* автоматический выход при компрометации аккаунта.

---

# 4. Профиль пользователя

Поля профиля:

* имя;
* фамилия;
* никнейм;
* аватар;
* описание;
* дата регистрации;
* язык;
* часовой пояс;
* статус;
* дата рождения (необязательно);
* ссылки на социальные сети (необязательно).

Настройки приватности позволяют управлять видимостью:

* номера телефона;
* email;
* времени последней активности;
* статуса "в сети";
* фотографии профиля;
* списка контактов.

---

# 5. Контакты

Функции:

* импорт контактов;
* поиск пользователей;
* добавление по QR-коду;
* добавление по никнейму;
* приглашение друзей;
* избранные контакты;
* блокировка пользователей.

---

# 6. Личные чаты

Поддержка:

* мгновенной доставки сообщений;
* подтверждений отправки и прочтения;
* индикатора набора текста;
* голосовых сообщений;
* видеосообщений;
* файлов;
* фотографий;
* видео;
* документов;
* GIF-анимаций;
* стикеров;
* эмодзи;
* реакций;
* ответов на сообщения;
* пересылки;
* цитирования;
* редактирования;
* удаления (для себя и для всех, в рамках политики сервиса);
* закрепления сообщений;
* поиска по переписке;
* форматирования текста;
* ссылок;
* превью ссылок.

---

# 7. Группы

Возможности:

* создание групп;
* публичные и приватные группы;
* роли участников;
* модераторы;
* администраторы;
* владельцы;
* приглашения по ссылке;
* QR-приглашения;
* закрепленные сообщения;
* медиа-раздел;
* поиск сообщений;
* журнал действий администрации;
* настройка прав участников;
* автоматическая модерация;
* приветственные сообщения.

---

# 8. Каналы

Поддержка:

* публичных каналов;
* приватных каналов;
* комментариев (опционально);
* реакций;
* закрепленных публикаций;
* аналитики просмотров;
* запланированных публикаций;
* нескольких администраторов;
* проверки прав перед публикацией.

---

# 9. Голосовые звонки

Функции:

* HD-аудио;
* шумоподавление;
* эхокомпенсация;
* выбор устройства ввода и вывода;
* переключение между устройствами;
* отображение качества соединения;
* сквозное шифрование.

---

# 10. Видеозвонки

Поддержка:

* HD;
* Full HD;
* демонстрации экрана;
* записи (при наличии согласия участников);
* размытия фона;
* виртуального фона;
* групповых звонков;
* сетки участников;
* автоматического выбора качества.

---

# 11. Голосовые комнаты

Функции:

* комнаты без ограничений по времени;
* модераторы;
* поднятие руки;
* отключение микрофонов;
* запись;
* приглашения;
* трансляция.

---

# 12. Передача файлов

Поддержка:

* документов;
* архивов;
* изображений;
* видео;
* музыки;
* PDF;
* презентаций;
* таблиц.

Дополнительно:

* докачка файлов;
* отображение прогресса;
* предпросмотр;
* антивирусная проверка (при необходимости).

---

# 13. Облачное хранилище

Пользователь получает:

* сохраненные сообщения;
* личное облако;
* синхронизацию между устройствами;
* историю загрузок.

---

# 14. Поиск

Поиск осуществляется по:

* сообщениям;
* пользователям;
* каналам;
* группам;
* документам;
* фотографиям;
* видео;
* ссылкам;
* дате;
* отправителю.

---

# 15. Уведомления

Поддерживаются:

* Push;
* Email;
* Desktop;
* Web Push;
* настройка звуков;
* отдельные настройки для каждого чата;
* режим "Не беспокоить";
* расписание уведомлений.

---

# 16. Настройки

Пользователь может изменить:

* тему оформления;
* язык;
* размер шрифта;
* цветовую схему;
* автоматическую загрузку медиа;
* автосохранение;
* качество звонков;
* качество видео;
* параметры конфиденциальности;
* настройки безопасности.

---

# 17. Безопасность

Реализовать:

* TLS для передачи данных;
* сквозное шифрование (для поддерживаемых типов чатов);
* шифрование данных на сервере;
* защиту от подбора паролей;
* ограничение количества запросов (Rate Limiting);
* журнал входов;
* управление активными устройствами;
* уведомления о входе с нового устройства;
* резервное копирование (в соответствии с выбранной моделью хранения и шифрования).

---

# 18. Административная панель

Функции:

* управление пользователями;
* управление жалобами;
* просмотр логов;
* управление каналами;
* управление группами;
* модерация контента;
* управление блокировками;
* аналитика;
* мониторинг серверов;
* резервное копирование.

---

# 19. API

Необходимо разработать:

* REST API;
* WebSocket API;
* gRPC (опционально).

API должно обеспечивать:

* авторизацию;
* сообщения;
* пользователей;
* файлы;
* звонки;
* уведомления;
* группы;
* каналы;
* поиск.

---

# 20. Производительность

Требования:

* доставка сообщений менее чем за 300 мс при нормальной нагрузке;
* поддержка миллионов пользователей;
* горизонтальное масштабирование;
* кэширование через Redis;
* балансировка нагрузки;
* CDN для медиа;
* асинхронная обработка задач.

---

# 23. Масштабируемость

Архитектура должна поддерживать:

* микросервисный подход (или модульный монолит с возможностью перехода к микросервисам);
* независимое масштабирование сервисов;
* распределенные очереди;
* географически распределенные дата-центры;
* автоматическое восстановление после сбоев.

# 26. Результат

В результате должен быть создан безопасный, производительный и масштабируемый мессенджер с современным интерфейсом, поддержкой общения в реальном времени, синхронизацией между устройствами, обменом файлами, группами, каналами, голосовыми и видеозвонками, а также возможностью дальнейшего расширения функциональности.
